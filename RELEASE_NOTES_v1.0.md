# Cortist Reality Ledger — Initial Public Evidence Snapshot (v1.0)

**Research dataset · Initial snapshot: 25 October 2026 · 10 cases · 12 source references**

This release preserves the first public Cortist Reality Ledger dataset: ten individually versioned evidence records about consequential artificial-intelligence claims, industry announcements, and research findings. The records identify original sources, describe what is supported and what remains uncertain, and specify future evidence needed for reassessment.

Included:

- Ten **unchanged v1 JSON snapshots** in `snapshots/`, one per record CL-0001–CL-0010.
- A **normalized, newline-delimited JSON** file `records.jsonl` for direct research use.
- **PROVENANCE.json** containing canonical URLs, per-snapshot SHA-256 hashes and release context.
- **DATA_DICTIONARY.md**, README and explicit CC BY 4.0 license scope.

**Not a claim of independent validation.** The dataset represents dated Cortist editorial evidence notes, not verified ground-truth labels, an AI safety certification or a scored forecasting benchmark.
